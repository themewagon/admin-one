## Getting Started

1. Clone Repository
```
git clone https://github.com/themewagon/admin-one.git
```
2. Install Dependencies
```
npm i
```
3. Run the development server:

```bash
npm run build:dev
# or
yarn dev build:dev
# or
pnpm dev build:dev
# or
bun dev build:dev
```
